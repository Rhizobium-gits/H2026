【進行中のプロジェクト】

* 同一生活圏における生活環境の差異が学生の文化・心理に与える影響の定量評価

研究の分類
	継続研究

実験準備期間
	2026-01-28

実験実施期間
	2026-04 --- 2027-01

実験成果収集期間
	2027-02 --- 2027-03

研究目標
	研究背景
イータヴィレッジという生活圏や食事生活リズムが極めて似通った学生が暮らすエコシステムにおける大きな差異の一つに棟ごとに暮らしている学生の性別的な構成の違いが挙げられる．

研究目標
この環境の違いが，学生の心理にどのような変化をもたらすのか，そしてどのように学生文化が構築されるのかをアンケート調査を通して時間列解析をもとに定量することを目指す．

継続研究としての新規性・目標
アンケート回答者数と回収頻度を増やすことで，先行研究よりもデータを堅牢にする．
4月の新寮生の入寮時アンケートを得ることでコミュニティ形成を正しく評価し直す．先行研究では5月からのアンケートだったせいもあってか有意な変化を観測できなかった．

成果発表
	プレプリントとしてSocArXivに掲載する
学会発表(どこの学会で発表するかは要検討)

研究費の出所
	LINOAのagora研究費の獲得を目指す

研究費使用の内訳
	アンケート継続回答者30名に抽選でスタバカードを配布(-¥30,000)
学会参加のための交通費とポスター印刷代(-¥20,000)

フォームの公開と非公開とデータの管理　データ管理者

2月前までのデータを解析・論文執筆・公開　研究代表者
