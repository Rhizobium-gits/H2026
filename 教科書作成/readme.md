研究目標
	プロジェクト背景
分子生物学を学ぶ世界中の学生の多くがエッセンシャル細胞生物学(全20章構成)を活用している．この教科書はおおかた丁寧な説明を美しい図表と共に掲載しているのが魅力である．しかし，文量が多く書いてあることを理解しながら1章を完全に読み切るには長いと5時間かかる(1章約40ページ)．また，書籍は非常に大きく分厚いため電車や出先で読むことは多くの場合困難である．このような物理的な制約に加え，この書では生体内で起きているAtoBtoCandDwithEandFのような複雑な一連の相互作用を一様にシステマチックな形式でまとめておらず，多くが簡易版のFigureを最初に掲示し，その後詳細に関してはバラバラと説明が進んでいる．脳死で読んでいると結局どことどこの間にどんな作用があるのかを多くの場合読んでいる間に忘れてしまう．

プロジェクト目標
そこで，当初の流れを示す概要図に詳細の現象の説明までを盛り込んだ章ごとの生命システムの全体の概要をまとめ直した決定版の作成を行う．

プロジェクトの詳細
エッセンシャル細胞生物学では1-11章までの多くは基礎的な内容で，わざわざまた一から丁寧に読み直すほどではない(生物基礎レベル)の内容が存在する．これらの基本的な生命現象の”把握”は単語リストレベルでまとめた方がラーニングコストが明らかに低くなる．
しかし，それ以降の16-20章などはこの把握をもとに複雑な生命システムを読み解いていく傾向がある．さらに，実際の病理的な知見などもまとめられているが，全てのレイヤーが一様に文章化されているため，知識の抜け落ちや特徴づけがなっていない．そこでこれらの内容はコラムという形で現象の傍に据えて見えるかしたほうが明らかに見やすくなる．
最後に，本書ではこのレイヤーを把握しやすくするために視覚的な差異を重視する．同じレイヤーのもの(例えば酵素)では他のレイヤー(例えば遺伝子)の文字の色を区別することでこれとこれは同じレイヤーのものだったな，とか酵素が遺伝子の転写活性をするからこの名前の物質からこの名前の物質がやりとりしているのだな，ﾎｳこの全体像におけるっこの抑制の矢印はそういう意味だったのか，といった具合で読めるような教科書を作りたい．
生命システムは美しく，細胞生物学を知ることはカフェインはどこに働き何が起きて目が覚めるのか，バイアグラが生体内で何をしているのか，ATPは筋肉をうごかるエネルギーと言われる所以はなぜなのか，いつどこでどのように動いているのかといったことがもはやロボットを見ているのかと思うくらい機械的に理解することができる．
この視座は，将来の生命の不可解さにつながり研究すべきこと，実際にまだ謎に包まれているのは何なのか判断する力の育成にもつながると信じている．
